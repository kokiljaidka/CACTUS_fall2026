Concept

Messy data is normal

Missing values

Empty cells, “N/A”, “unknown”, “-”.

Duplicates

The same row twice, or the same post collected twice.

Wrong types

Dates and numbers stored as text.

Uneven groups

Some countries have thousands of rows and others a dozen.

Cleaning is not a failure of the data. It is part of the analysis, and each step needs a reason.

The habit

Three checks for any result

Count the rows

Before and after each step. What changed, and why?

Check by hand

Pick three rows. Work the answer out yourself.

Use a second method

Get the same number a different way. Do they match?

Write each check in your verification log. A check you did not record is a check you will forget.

CACTUS Fall 2026 · Week 2

The idea behind this week

Silent changes

A step can drop rows, swap values, or merge groups, and print no error. The only way to know is to check what it did.

A filter loses rows

A merge drops unmatched rows

An average hides group sizes

What to do next

Before the coding session

Practice page

Silent Changes, about 20 minutes. It ends with a small coding task for Colab.

Required reading

Textbook Chapter 6, sections 6.1 to 6.4, and Chapter 4, section 4.2 on errors.

Bring

A laptop, the Starbucks file ready to upload, and your verification log.

Stuck for five minutes? Read the last line of the error, re-read the step, ask your partner, ask the AI, then ask for help.
