The idea behind this week

Silent changes

A step can drop rows, swap values, or merge groups, and print no error. The only way to know is to check what it did.

A filter loses rows

A merge drops unmatched rows

An average hides group sizes

This slide introduces the practice page. The page lets you build a cleaning pipeline and watch a row-count waterfall, then hunt three bugs that run without any error. These are different bugs from the live exercise, so it does not give that away. Do it after this session and before the coding session. It takes about twenty minutes.
