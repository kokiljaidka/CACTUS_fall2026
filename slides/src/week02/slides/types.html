Concept

Types: the same-looking value can behave differently

Number

12

Text

"12"

Date

2024-10-05

True / false

True

A number stored as text looks the same and behaves differently. "1" + "2" makes "12". A date stored as text cannot be sorted by time.

Callback to the puzzle page from last week: quotes made a value text. In real data the same thing happens silently when one bad cell, like "unknown", forces a whole column to be read as text. Then averages fail or mislead. Check types early: df.info() shows them.
