The checklist

Before you share the link

Runs

Restart and run all works. Paths are relative. Packages are installed in the notebook.

Safe

No keys, passwords or private data, in the code or in the saved outputs. Keys live in Colab Secrets.

Documented

A data card, your verification log, and a short README that says how to rerun it, how long it takes, and the model and date for any AI step.

If a key was ever pushed, replace it. Deleting the file does not remove it from the history.
