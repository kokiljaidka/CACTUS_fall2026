Ten minutes, no code. The restaurant analogy: you do not walk into the kitchen. You send an order in a fixed format (dish, size, table number), and the kitchen sends back the dish. In Session 2 you will see exactly this with real data, and you will practice the ideas behind it (variables, lists, dictionaries, functions) in a puzzle page first.
